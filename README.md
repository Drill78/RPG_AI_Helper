# RPG AI Helper

一个面向多领域的 AI 使用辅助平台，帮助用户学习方法、完成实际任务、检查成果，并与伙伴协作。

RPG 元素用于辅助理解学习领域、工具、实操方案和阶段进度，产品以清晰和实用为先。

## 首期方向

- 通用 AI 实践：跨领域的 AI 使用方法、日常任务与可复用工作流。
- 游戏制作人：以具体成果为目标的游戏制作学习与实践。
- 三人内部协作：个人学习记录、团队任务和共同目标。

## 长期方向

扩展更多职业领域，推出手机 App，并逐步支持好友组队学习和用户发布小任务。

## 当前状态

项目处于需求设计与开发环境准备阶段。本次初始化仅建立仓库基础文件，尚未实现应用功能，也尚未确定技术栈。

先确认项目方案，再细化页面、内容条目与验收标准，然后进入应用开发。
