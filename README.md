# 行会 AI · RPG AI Helper

**把好奇变成能力，把方法变成作品。** 一个以实际成果为中心的 AI 学习与三人协作工作台。

RPG 是界面与组织知识的轻量隐喻：公会是学习方向，卷轴是可复用的提示词配方，装备是工具，共同目标可以叫 Boss。学习内容和实际操作优先，界面采用成年向奇幻像素美术。

![行会档案馆](public/images/hero-dark.png)

## 已实现

- **通用 AI 实践与游戏制作人**：两个方向、20 个完整节点，含准备条件、方法、动手练习、成果检查与官方参考资料。
- **20 份提示词配方**：变量填写、实时组合、直接编辑、复制、个人收藏、保存为提示词笔记，附材料、步骤和结果核验。
- **13 张工具卡**：用途、费用说明、使用边界与官方入口。
- **个人学习记录**：按真实检查清单标记完成；三个成员独立记录进度、收藏和笔记。未保存笔记草稿可在当前浏览器窗口内恢复。
- **小队任务板**：创建、编辑、指派、优先级、日期、拖动或菜单切换状态、删除；手机尺寸采用状态标签页。
- **共同目标**：可编辑目标、截止日期和里程碑，不以虚构经验值衡量成果。
- **完整本地工作区**：SQLite 持久化、JSON 导入导出、成员资料编辑、全局搜索、键盘导航、错误与冲突反馈。
- **数据保护**：事务写入、严格导入校验、基于 ETag 的版本冲突检测，避免多个窗口互相覆盖记录。

## 在这台 Windows 电脑上打开

双击项目根目录里的 **`Start-Workspace.cmd`**。它会检查环境、构建页面、在后台启动本地服务，然后打开：

**http://127.0.0.1:4174**

已安装的依赖可直接使用。需要 Node.js 24 或更新版本；启动器也可以找到 Codex 附带的 Node 运行时。详细步骤、停止方式与故障排查见 [本地启动说明](docs/LOCAL_SETUP.md)。

日常操作见 [使用指南](docs/USER_GUIDE.md)。

## 开发与验证

```sh
pnpm install --frozen-lockfile
pnpm dev            # 前端 4173，API 4174
pnpm build          # 类型检查 + 生产构建
pnpm start          # 在 4174 提供构建页面与 API
pnpm test           # HTTP / SQLite / 内容完整性
pnpm exec playwright install chromium
pnpm test:e2e       # 独立临时数据库，端口 4178
```

浏览器测试运行前需重新 `pnpm build`。测试不会使用真实的 `data/workspace.sqlite`。无障碍检查可在 `pnpm dev` 运行时执行 `node scripts/accessibility.mjs`。

## 数据与适用范围

- 业务数据保存在 `data/workspace.sqlite`，不会提交到 Git；备份优先使用界面上的「导出备份」。
- 服务仅监听本机。三个成员是本地档案，不是在线账号；其他电脑不会自动看到这里的数据。
- 应用帮助学习、组织任务与准备提示词，不内置付费 AI 调用，也不会假装已运行生成任务。
- 工具链接及参考资料需要联网访问；页面、字体、美术和已有学习内容均由本地服务提供。
- 手机尺寸适配已实现；原生手机 App、好友组队、跨设备同步和用户任务发布属于后续规划。
