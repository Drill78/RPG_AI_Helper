# 行会 AI · 本地版使用指南

适用版本：0.3 · 更新于 2026-10-09

行会 AI 是一个帮助你学习 AI 方法、整理提示词和推进实际任务的工作台。公会就是学习方向，工具装备就是实际软件，Boss 就是想一起完成的目标。无需先记住游戏规则，直接从一件想完成的事开始。

## 第一次打开

1. 打开项目文件夹 `C:\Users\ROG\Documents\Projects\RPG_AI_Helper`。
2. 双击 `Start-Workspace.cmd`。请把它留在完整项目文件夹里，不要单独移到其他位置；需要桌面入口时可以创建快捷方式。
3. 等待启动器准备页面，浏览器会自动打开 `http://127.0.0.1:4174`。
4. 如果工作区已经运行，再次双击会直接打开现有页面。关闭启动窗口不会关闭后台工作区。

首次在一台新电脑运行需要 Node.js 24 或更新版本。缺少项目依赖时，启动器会尝试通过 pnpm 安装已锁定的依赖，这一步需要联网。当前电脑已经准备好的环境可直接使用。

如果出现“还没有连接到本地工作区”，先重新运行启动文件，再点击“重新连接”。读取或保存时发现连接中断，会出现错误提示条；可以点击其中的“重新连接”，也可以点击顶部连接状态刷新工作区。出现失败提示的修改不能视为保存成功，恢复连接后核对内容再重试。启动器显示错误时，把完整提示发给 Codex；不要反复删除项目或数据目录来尝试修复。电脑重启后，再双击启动文件即可。

## 用十五分钟走完一次真实流程

1. 在左下角确认当前成员。
2. 打开“学习公会”→“通用 AI 实践”→“把模糊想法变成一张任务卡”。
3. 先读“这次你会做出什么”，再完成准备和讲解。
4. 点击“打开配套提示词”，把示例换成今天真实要做的事。
5. 复制提示词，粘贴到自己正在使用的 AI 工具里运行。
6. 按课程要求检查结果，回到课程勾选已经实际验证的项目。
7. 写一条实践笔记并点击“保存笔记”；全部检查通过后点击“完成这个节点”。

这一步记录的是你亲自完成的练习，不是系统替你运行过 AI，也不是职业认证。时间只是练习参考，遇到不熟悉的工具可以按自己的节奏继续。

## 页面怎么用

| 导航         | 可以做什么                                               |
| ------------ | -------------------------------------------------------- |
| 冒险起点     | 查看当前成员的进度、提示词笔记数量、待办任务和下一项实践 |
| 学习公会     | 浏览通用 AI 实践和游戏制作人的课程路线                   |
| 提示词工坊   | 按方向、难度或关键词找配方，填入需求、编辑和复制         |
| 工具装备库   | 看工具的实际用途、费用说明，并打开官方页面               |

| 我的收藏     | 查看收藏的配方、保存的提示词版本和实践笔记               |

窄屏下点击顶部菜单按钮展开导航。课程、配方和工具也可以通过顶部搜索查找；点击工具结果会进入工具库、滚动到对应卡片并突出显示它。顶部连接状态可以点击，用于主动读取工作区的最新记录。

## 学习路线与成果检查

当前有两条路线，共 20 个实践节点：

- **通用 AI 实践**：从任务表达、资料整理和日常协作，走到信息核查、表格、知识复用、小自动化和工作流评测。它不限于新手。
- **游戏制作人**：从一页游戏计划、引擎与输入，走到完整一局、调试、素材、协作、试玩、导出和迭代。低模 3D 是可选支线，制作 2D 游戏不必先完成建模。

可以按路线学习，也可以直接进入当下需要的节点。LV.1～LV.5 表示成果阶段，不锁定访问顺序，也不代表统一能力分数。其他公会在页面中标为“规划中”，还没有可进入的课程。

课程右侧“成果检查”勾选后会保存到当前成员。只有逐项确认后，才能记录整个节点完成；取消某项检查会让该节点恢复为未完成。已经完成的课程仍可打开，点击“已完成 · 重新学习”可重新记录学习状态。

课程正文底部的“我的实践笔记”适合保存成果链接、遇到的问题和复盘。尚未保存的文字会暂存在**当前浏览器标签页**：在同一标签页内切换页面或刷新后，通常可以继续编辑，切换成员也不会把草稿混到另一人名下。草稿不等于工作区记录，不会同步到其他标签页、收藏中的实践笔记或导出的备份里；关闭标签页、清理浏览器数据或浏览器限制存储时，不能依赖它恢复。

点击“保存笔记”并确认成功后，文字才写入本地工作区、进入备份范围。保存过程中继续输入的文字仍是草稿，需要再保存一次。重要内容应及时手动保存，不把浏览器草稿当作正式备份。

同一篇笔记在其他窗口被修改后，读取最新状态时会区分两种情况：本窗口没有编辑，文本框直接跟随最新保存版本；本窗口已有草稿，则保留草稿并显示冲突提示，刷新页面后也会保留这个待处理状态。此时可以选择“载入已保存的新版本”，用最新记录替换编辑区的草稿；也可以点击“确认用草稿替换已保存版本”，明确保存自己的文本。如果两边都需要保留，先复制自己的草稿，再载入新版整理合并后保存。系统不会替你自动合并两份文字。

来源链接在课程底部，会在新标签页打开；具体软件界面可能因版本不同而变化。

## 制作一份自己的提示词

1. 在提示词工坊选择配方。每份配方都有用途、材料、操作步骤和验收方法。
2. 在“制作你的提示词”页填写左侧字段。标为“示例”的内容需要换成自己的实际情况，尤其是引擎版本、项目进度和测试结果。
3. 右侧会按输入组成完整提示词。没有填写的字段会显示“请填写”标记，建议补齐后再使用。
4. 可以直接编辑右侧文本。此时改动左侧字段会重新生成右侧内容；先完成左侧填写，再做最后润色更稳妥。
5. “恢复模板”是按**当前左侧输入**重新组成文本，不会把左侧恢复为初始示例。
6. 点击“复制提示词”，到自己的 AI 工具粘贴运行。若需要附件，请在那个 AI 工具里另行上传；这里只填写文件名不会自动传递文件。
7. 满意后点击“保存为我的笔记”，把当前文本保存在当前成员名下。

“收藏配方”保存的是配方入口；“保存为我的笔记”保存的是这一次填好、改好的文本。两者可以同时使用。界面没有内置 AI 推理，也不会因为点击复制或保存而消耗外部 AI 额度。

切换到“使用指南与检查”，可以查看操作顺序、结果检查和常见失败点。无法联网、不能读附件或不能执行代码的 AI 工具，不会因为收到提示词就自动获得这些能力；按模板给出的替代步骤处理即可。

## 三个本地成员怎样使用

点击左下角成员区，可以在三份本地档案之间切换。在“工作区与指南”中修改名称和一句话介绍后，点击对应的“保存”。

| 独立保存到每位成员   | 三位成员共同使用           |
| -------------------- | -------------------------- |
| 课程检查项与完成进度 | 同一套课程、配方与工具资料 |
| 实践笔记             | 共享任务板及任务负责人     |
| 配方收藏             | 共同目标和里程碑           |
| 保存的提示词文本     | 成员名称与介绍             |

这不是三个联网账号，也没有密码或隐私隔离。使用这台电脑的人可以切换到其他成员。换浏览器时可能回到默认成员，先检查左下角名字，再判断是否真的少了记录。

如果多个窗口同时修改工作区，保存时可能提示“工作区已在其他窗口更新”。系统会拒绝这次基于旧记录的修改，并读取最新状态，避免覆盖另一窗口刚保存的数据。请核对最新内容，再重试这一次操作；不要把冲突提示误认为已经保存成功。如果同时出现连接失败提示，先重新连接。实践笔记若出现前述冲突提示，先选择采用哪个版本；系统不会自动重放原来的修改。

## 用任务和共同目标推进小项目

**创建任务：**在“小队任务板”点击“创建任务”，填写具体成果、完成标准、负责人和状态。日期可留空；重要的事项可以标为“优先推进”。保存后出现在对应的一列。

**更新状态：**将卡片拖到“待开始”“进行中”或“已完成”，也可以用卡片底部的状态菜单移动。触屏或键盘操作优先使用状态菜单，无需拖动。

**手机尺寸布局：**任务板一次显示一个状态，通过上方“待开始 / 进行中 / 已完成”页签切换。卡片移到另一个状态后，会从当前页签消失；点击目标状态即可找到它。页签旁的数量会跟随“全部任务 / 只看我的”筛选变化。这是窄屏网页布局，当前服务仍只能在运行它的电脑上访问。

**编辑或删除：**点击任务标题或右上角编辑按钮。删除需要再次确认；不要用删除代替完成。如果之后要恢复已删除记录，需要已有备份。

**只看自己的任务：**选择“只看我的”，列表使用左下角当前成员作为负责人筛选。切换成员后看到的任务会随之变化；“全部任务”显示全队任务。

**共同目标：**点击“设定目标”，写出最终成果，再拆成几个可验证的里程碑。例如“交付一个可试玩小游戏”可以拆成计划确认、完整一局、伙伴试玩和导出交付。完成一个阶段后勾选对应里程碑，目标进度会更新。

任务状态与目标里程碑当前是分别记录的。将任务移到“已完成”，不会自动勾选某个目标；课程完成也不会自动替你完成任务。需要时依据实际结果分别确认。

初始任务和目标带有“示例”标记，可以编辑成自己的内容，也可以删除。它们不表示三位成员已经完成这些工作。

## 找回收藏与笔记

“我的收藏”有三个页签：

- **配方收藏**：快速回到收藏过的原始配方；取消收藏不会删除此前保存的文本笔记。
- **提示词笔记**：打开已经保存的文本，可以复制或删除。保存内容是一个文本快照，原始配方以后更新时不会自动改写它。
- **实践笔记**：显示课程中保存的记录；点击可回到对应课程继续修改。

要调整一份已保存提示词，可以复制它，回到适合的配方页面编辑右侧文本，再保存新的笔记。当前没有独立的笔记改名或版本合并功能。

## 备份与换电脑

在“工作区与指南”点击“导出备份”，浏览器会下载 JSON 文件。它包含三位成员的进度、实践笔记、收藏、共享任务、目标和保存的提示词；不包含课程源码、应用程序或外部 AI 对话。

进行大幅调整或导入旧记录前，先导出一份当前备份。可以按日期保存，例如 `行会AI-2026-10-09.json`。课程笔记只有点击“保存笔记”成功后才会导出；当前标签页暂存的课程草稿不在备份中。提示词也只有点击“保存为我的笔记”成功后才会导出，提示词编辑区目前没有同样的标签页草稿恢复功能。

恢复时点击“导入备份”，选择文件，检查预览中的成员、任务和目标数量，再确认恢复。**导入会整体替换当前工作区，不是把两份数据合并。** 文件校验失败不会部分覆盖现有数据。

换电脑的步骤是：在原电脑导出 JSON → 在新电脑准备并启动完整项目 → 导入 JSON。GitHub 保存的是项目代码，不会自动同步你的本地学习数据库。

本地数据文件位于项目的 `data/workspace.sqlite`。日常迁移优先用界面导出，不要在服务运行时随意移动或只复制单个数据库文件。关闭浏览器、关闭电脑后，已经保存的数据仍在；再次开机需要重新运行启动入口。

## 键盘操作

| 操作                         | 快捷键或方式                                  |
| ---------------------------- | --------------------------------------------- |
| 打开或关闭全局搜索           | Windows：Ctrl + K；macOS 浏览器：Command + K  |
| 关闭弹窗、成员菜单或窄屏导航 | Esc                                           |
| 依次移动焦点                 | Tab；反向使用 Shift + Tab                     |
| 激活当前按钮或勾选项         | Enter 或空格，按控件类型使用                  |
| 剪贴板按钮不可用时复制文本   | 在文本框内全选，再使用 Ctrl + C / Command + C |
| 在当前页面查找文字           | 浏览器自带的 Ctrl + F / Command + F           |

第一次按 Tab 可使用“跳到主要内容”跳过侧边导航。任务状态也有下拉菜单，不要求使用鼠标拖拽。课程目录可以直接跳到正文对应段落。

## 当前版本的范围

- 服务只监听本机地址，其他电脑或手机不能直接访问这台电脑的 `127.0.0.1`。
- 页面适配窄屏，但目前还不是已上架的手机 App。
- 没有公网账号、好友邀请、跨设备实时同步或用户任务市场。
- 没有内置 AI 聊天、自动执行提示词或付费模型 API 调用。
- 课程内容和软件价格会变化，工具卡的说明用于帮助选择，使用前查看当前官方资料。
- 学习检查由使用者自行确认；平台不替代专业评审，不颁发职业能力认证。

后续方向见[发展路线](ROADMAP.md)；课程归属与编写规则见[内容编写规范](CONTENT_GUIDE.md)。这两份文档中的未来能力不表示已经上线。
