# 在这台电脑上使用工作区

## 日常打开

在项目文件夹中双击 **`Start-Workspace.cmd`**。启动器会检查环境，必要时安装已锁定的依赖，构建最新页面，在后台启动服务，确认就绪后打开浏览器：

**http://127.0.0.1:4174**

已有同一个工作区在运行时，启动器直接打开页面，不会重复启动。第一次安装依赖需要网络；依赖已就绪后的构建与本地学习记录不依赖联网。访问外部资料、把提示词用于其他 AI 产品仍需要相应服务可用。

后台运行的工作区不会因为关闭启动窗口而退出。电脑重启后再次双击即可。关闭浏览器不会清空学习记录。

## 环境如何找到

启动器先检查系统 PATH 中的 Node.js，再检查当前用户的 Codex 附带运行环境。要求 Node.js 24 或更新版本。它不会写死某位用户的用户名，也不需要把 Codex 的路径手动加入系统配置。

依赖未安装时，先寻找 PATH 中的 pnpm，再检查 Codex 附带的 pnpm。如果两处都没有，启动器会清楚提示缺少什么，不会擅自安装软件管理器或修改系统设置。需要人工准备时，可安装 Node.js 24 与 pnpm，然后在项目目录运行：

```text
pnpm install --frozen-lockfile
```

启动器只在项目自己的进程中临时补充 Node 路径。它不会改变全局环境变量、关闭防火墙或开启远程访问。

## 开发与更新

编码时在项目目录运行：

```text
pnpm dev
```

开发页面为 **http://127.0.0.1:4173**，会同时启动前端热更新服务与 4174 端口的本地 API。已有本项目 API 时会复用它；按 Ctrl+C 仅关闭本次开发命令启动的服务，不会关闭预先存在的 API。

验证与生产构建：

```text
pnpm test
pnpm build
pnpm start
```

`pnpm start` 以前台方式运行，便于看到诊断信息；按 Ctrl+C 安全关闭。它使用已经构建好的 `dist/`。日常双击启动器在未运行服务时会重新构建，保证加载最新页面。

如果编码期间已有后台服务，前端可通过重新构建更新；修改了服务端代码则需要确认并重启该项目进程。启动器不会为了更新去强制关闭已有程序。

只检查运行环境，不安装、不构建、不启动服务：

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\scripts\launch.ps1 -CheckOnly
```

## 数据与备份

三位成员的名称、学习进度、笔记、收藏、保存的提示词，以及共享任务和共同目标保存在 **`data/workspace.sqlite`**。这些个人数据不会提交到 GitHub。教程与提示词原始配方属于项目内容，由代码版本管理。

推荐使用应用内的 **导出备份**，得到包含三位成员完整工作区的 JSON。恢复时使用 **导入备份**；导入会整体替换当前数据，建议先导出当前版本。

需要直接复制数据库文件时，先安全停止服务，再备份 `data/` 整个文件夹。运行中的 SQLite 可能包含尚在 WAL 文件里的已提交内容，只复制一个 `.sqlite` 文件不保证完整。不要删除 `data/` 来处理页面问题。

## 常见提示

| 提示                 | 处理方式                                                          |
| -------------------- | ----------------------------------------------------------------- |
| 没有找到 Node.js 24  | 在 Codex 中打开项目重试，或安装 Node.js 24；启动器会显示缺失项    |
| 没有找到 pnpm        | 依赖尚未就绪时才需要；在 Codex 中安装项目依赖，或准备 pnpm 后重试 |
| 依赖安装失败         | 检查网络，并保留窗口中的具体报错                                  |
| 检查或构建失败       | 把窗口中第一条实际错误交给 Codex 修复；不影响已有学习数据         |
| 4174 被其他程序占用  | 先确认占用者；启动器不会擅自关闭进程                              |
| 4173 被占用          | 通常已有开发服务；尝试打开开发地址，确认后再决定是否关闭          |
| 服务启动失败         | 查看 `.local/logs/` 最新的 `.err.log` 与 `.out.log`               |
| Windows 阻止运行脚本 | 保留提示并交给 Codex 处理；不要为此关闭系统整体安全策略           |

## 当前版本的边界

这是 **本机内部工作区**：三位成员是可切换的本地档案，不是联网登录账户。服务只监听 `127.0.0.1`，其他电脑或手机无法直接通过家中电脑 IP 打开它。页面有适合窄屏的布局，但不是已经发布的原生手机 app。

目前无需填写 AI API 密钥，也不会在后台调用付费模型。你可以编辑、复制提示词，然后到自己选择的 AI 工具中执行。软件不会伪造一次 AI 已经执行的结果。

Space 用于共同查看项目说明；GitHub 保存代码。另一台电脑上的本地学习数据、后台进程与当前电脑不会自动同步。后续需要远程访问、账号与好友、组团学习、手机应用时，再接入相应服务与权限设计。
